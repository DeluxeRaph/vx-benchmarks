# Vx Benchmarks

GPU kernel benchmarks for [Vx](https://github.com/vx-lang/Vx), compared with CUDA.

Benchmarks run on a Jetson Orin Nano 8GB, which has an [NVIDIA Ampere GPU with 1,024 CUDA cores](https://developer.nvidia.com/blog/develop-ai-powered-robots-smart-vision-systems-and-more-with-nvidia-jetson-orin-nano-developer-kit) (compute capability 8.7).

I’m new to benchmarking GPU kernels, so take these results with a grain of salt.

First test: [vector addition results and methodology](benchmark/REPORT.md). Sources and raw measurements are included. See [SETUP.md](SETUP.md) to run the tests.
